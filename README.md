# الذكاء الاصطناعي في المجالات الإبداعية: عرض الورشة

هذا فرع `main`: نسخة المشاركة العامة، وفيها السلايدات فقط (01–34) كموقع ثابت يُستضاف على GitHub Pages تحت
`/ai-creative-workshop/`. المشروع الكامل (الأغلفة، المعمل، نافذة المقدّم، ملاحظات الإلقاء، وضع التطوير، صفحة
المراجع) في فرع `dev`، والتطوير كله هناك. إلى `main` تُنقل تغييرات السلايدات اللازمة للمشاركة فقط، بدون دمج
`dev` كاملًا.

```sh
npm ci
npm run dev       # http://localhost:3000/ai-creative-workshop/
npm run build     # يبني الموقع الثابت في out/
```

## التنقل
- النقر أو المسافة أو ← أو ↓ للمرحلة التالية، و→ أو ↑ أو النقر بالزر الأيمن للرجوع. Shift مع الأسهم يقفز سلايدًا كاملًا.
- على الجوال: لمسة للتالي، وسحب الإصبع لليسار للتالي ولليمين للرجوع.
- `R` إعادة السلايد، `F` ملء الشاشة، `O` كل السلايدات، ورقم السلايد ثم Enter للانتقال إليه.
- الرابط يحمل رقم السلايد (`/ai-creative-workshop/#07`)، فيفتح أي سلايد مباشرة ويبقى عليه بعد التحديث.

## النشر على GitHub Pages (لاحقًا)
1. في إعدادات المستودع: Settings ← Pages ← Source: **GitHub Actions**.
2. من تبويب Actions شغّل «Deploy deck to GitHub Pages» يدويًا (Run workflow) على فرع `main`. لا يشتغل وحده عند الدفع.
3. يبني `npm run build` ويرفع مجلد `out/`، والموقع يكون على `https://<user>.github.io/ai-creative-workshop/`.

## ملاحظات البناء
- مسار المشروع في `next.config.ts` (`basePath`)، وكل ملف من `public/` يمر عبر `asset()` في `lib/asset.ts`.
- الخطوط في `assets/fonts/` (تضمّنها next/font في الحزمة)، وليست في `public/` حتى لا تتكرر.
- three.js (السلايدان 22 و33) في حزمة منفصلة تُجلب في الخلفية بعد ظهور العرض (`deck/kit/lazy3d.ts`)، والفيديو ومجسم الساعة يُحمَّلان عند فتح سلايدهما فقط.
