# الذكاء الاصطناعي في المجالات الإبداعية

مشروع Next.js وTypeScript وTailwind CSS لمعاينة أغلفة الورشة التفاعلية. يحتوي المعرض الأول على عشرة ثيمات، ويحتوي معرض المختبر الرقمي على سبعة أغلفة بدون ومضة وثلاثة يظهر فيها ظلّها. ويضيف معرض الأغلفة الإبداعية خمسة عشر غلافًا بدون شخصية.

```sh
npm ci
npm run dev
```

افتح [المعرض الأول](http://localhost:3000) أو [معرض المختبر الرقمي](http://localhost:3000/lab) أو [معرض الأغلفة الإبداعية](http://localhost:3000/studio). للإنتاج شغّل `npm run build` ثم `npm start`.

- افتح أي غلاف لتشغيل حركته. انقر على الغلاف أو اضغط المسافة أو السهم للأسفل للتقدم في مراحله. ينتقل العرض إلى الثيم التالي بعد آخر مرحلة. السهمان يمينًا ويسارًا يبدلان الثيم مباشرة، والسهم للأعلى يرجع مرحلة.
- استخدم زر إعادة الحركة لإعادة الغلاف من بدايته، وزر ملء الشاشة لإخفاء أدوات المعاينة. حرّك المؤشر إلى أعلى الشاشة لإظهار الأدوات، أو اضغط Escape للخروج.
- اختر ثيمين من بطاقات المعرض لعرضهما جنبًا إلى جنب. يُحفظ اعتماد الثيم محليًا في المتصفح. يظهر بعد الاعتماد زر بدء بناء السلايدات لإرشادك إلى إرسال المحتوى.

النصوص المشتركة في `presentation/content.ts`. تعريفات الثيمات وتكوينات الأغلفة في `presentation/covers/`، وحركاتها في `motion.css`. أدوات المعاينة والتنقل والمقارنة في `presentation/player/`.

تستخدم المعاينة التفاعلية في المعرض الأول والمختبر الرقمي [Gradient ASCII من React Bits](https://www.reactbits.dev/backgrounds/gradient-ascii) بإعدادات Atmosphere الأصلية وبحد دقة رسم 1 لتخفيف العبء أثناء العرض. تستخدم البطاقات والمقارنة لقطة من الخلفية نفسها، وتظهر اللقطة أيضًا إذا لم يتوفر WebGL. وفي معرض الأغلفة الإبداعية، يظهر المكوّن كنسيج خافت في «أفق الفكرة» وداخل العدسة في «الأسكي تحت السطح». مكوّن React Bits وترخيصه في `presentation/background/vendor/`.

خط ثمانية Sans وشعار ركايا من أصول المشروع المحلي. تحفظ اللقطات السوداء من مرجع ومضة في `public/wamda/`، والمرجع الأصلي في `source-assets/Wamda.mp4` خارج ملفات الويب العامة. يتيح `presentation/character/Wamda.tsx` حالات الإخفاء والظل والكشف ومظهر الشخصية بعد الكشف. تمرير أصل ملون مطلوب صراحةً في حالتي الكشف وما بعده.
